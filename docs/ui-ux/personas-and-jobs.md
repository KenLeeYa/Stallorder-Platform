# 角色與工作任務

以下為依既有權限與使用者回報建立的工作假設，未冒充訪談研究。

| 角色 | 高頻工作／完成定義 | 裝置與限制 | 介面決策 |
|---|---|---|---|
| 櫃檯店員 | 接單、改單、收款、確認交付；只完成一次 | 平板、手忙、多人共用設備 | 訂單狀態篩選、三區、固定操作區、清楚付款／列印問題 |
| 廚房人員 | 找待製作品項、批次製作、出餐 | 沾水、遠距閱讀、沒有收款權 | 保留 kitchen 聚合與權限；不把店員分頁強制套用 KDS |
| 商家負責人 | 售完／補量、商品維護、營業設定、排班與查看營運 | 電腦／平板；操作影響多攤位 | 類別群組層級、5 筆分頁、選取數量與攤位範圍警示 |
| 財務檢視者 | 指定日期／攤位查收入及差異 | 電腦；不可代收或退款 | 沿用報表權限、口徑與時間，沒有管理權不顯示變更入口 |
| 平台管理者 | 查看商家方案、健康、稽核與例外 | 電腦；高影響範圍 | 既有平台 guard；不新增 impersonation 或跨租戶捷徑 |
| 首次點餐顧客 | 看到可售餐點、完成必選、確認費用、追蹤原單 | 360px 手機、LINE 內建瀏覽器、弱網 | 訪客流程、持續可見欄位名、保留餐具及客製、阻擋原因明示 |
| 長者／低視力使用者 | 辨識品名、份數、金額及下一步 | 手機、平板、放大文字 | 大字延伸到資料區；觸控面積、換行與文字狀態；不只加大圖示 |

衡量代理指標：可見 DOM／按鈕數、找到指定單所需的搜尋／分頁步驟、欄位標籤是否持續存在、錯誤後資料是否保留。沒有真人樣本，不宣稱完成時間、滿意度或錯誤率的因果提升。
