# 店員功能列與外送／QR 改單：本機候選

範圍：`codex/ui-ux-redesign-20260923`，本機 3023／catalog-ops PostgreSQL 55722。未發布正式環境、未變更 DR、未新增 migration。

## 訂單流程

原本後端、前端可修改清單及修改視窗都把公開訂單限定在 `QR_MENU + TAKEOUT`。這次共用來源／狀態判斷，納入本系統 QR 內用、外送及 `LINE_DELIVERY + DELIVERY`。

- 店員可在待接單時增減或替換商品。QR 內用可能自動確認，因此延續外帶自取規則：已確認但尚未付款、尚未開始製作時也可由店員調整。
- 已確認的未來預約單可在「未來預約訂單」展開後修改；仍不開放提前製作。待確認預約單沿用原本待接單區入口。
- 顧客自行修改訂單的確認後限制不變。外部外送平台訂單未納入本次修改能力，避免未同步平台的費用與明細。
- 公開訂單必填原因與顧客訊息；保留原單號、既有行項目價格與客製快照。新增項目使用伺服器現價與必選驗證。
- 付款／折扣、開始製作、KDS 已開始、版本衝突、庫存不足仍擋下；以 `changeId` 保證重送不重複扣庫存或增加異動紀錄。
- 庫存、金額、KDS、稽核、顧客查單通知與已列印差異單沿用既有交易流程。已列印本身不再是全面禁止改單的條件，原始單據快照不覆寫，差異單註明勿製作／加做。

## 介面

- 電腦／平板常規功能保持圖示列，可水平捲動；手機只顯示主要操作與所有功能入口。聲音為常用開關，Web Push 訂單提醒設定收進所有功能。
- 搜尋圖示緊鄰桌位平面圖左側，開啟原生 modal，支援清除、確認、Escape、焦點返回；訂單清單維持篩選結果。
- 電腦／平板移除今日製作標題與說明，三欄明細保持滿版且各欄獨立捲動。訂單篩選和來源／翻頁置於緊湊控制區，翻頁箭頭保留完整無障礙名稱。
- 網路狀態預設只顯示色彩圖示，同時保留狀態名稱及滑鼠提示。其他使用 PwaControls 的商家／廚房／管理頁共享此預設。
- 長者模式維持較大文字與 56 px 功能觸控範圍，店員圖示列不展開成大尺寸文字卡。
- SSE 左側固定排列明暗模式、聲音、螢幕喚醒及有權限且已啟用的列印入口。「切換模式」目前依明暗外觀解讀；商家／店員／廚房身分切換保留於所有功能。窄螢幕可橫滑功能列。
