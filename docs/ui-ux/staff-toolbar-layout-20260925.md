# 店員看板功能列與篩選配置調整

範圍：`codex/ui-ux-redesign-20260923`，本機 3023、既有 catalog-ops DB 55722。依 2026-09-25 最新確認，左欄移除重複品項摘要與訂單備註。未發布正式環境、未更動 DR 或資料結構。

## 最終操作規則

- 768 px 以上：完整單排圖示，沒有「所有功能」按鈕。搜尋接在「產能與等候時間」右側；空間不足時可橫向捲到最後一個控制項，不擠壓圖示。
- 手機：保留主要操作及「所有功能」。頂端常用區依權限顯示商家／店員切換、聲音、喚醒、列印、SSE；明暗模式與 Web Push 設定留在展開的功能列。純店員未取得其他角色權限時不新增角色切換入口。
- 各尺寸移除「今日製作／逾期」及其說明。保留離線、列印故障及訂單驗證等必要訊息。
- 電腦／平板的篩選按鈕、來源下拉、最近一小時及翻頁同一列；來源緊接篩選區，翻頁在右端。畫面隱藏「訂單來源」文字，保留無障礙標籤。佇列按鈕不縮成直排；窄平板可橫滑篩選按鈕。
- 手機篩選預設收合成一列，摘要保留所選狀態、篩後筆數、來源及時間條件；可展開修改，收合不清除條件。
- 電腦／平板左欄保留訂單號、顧客識別、來源、時間、份數／金額、付款與列印狀態；品項完整內容在中欄，訂單備註在右欄。手機單張訂單仍保留必要細節。

本文件取代前一份報告中搜尋位於桌圖左側、頂端常用明暗模式、手機顯示今日標題，以及桌面部分工具須展開的規則。其他訂單、權限、改單及列印規則不變。
