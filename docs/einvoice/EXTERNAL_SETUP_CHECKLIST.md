# External Setup Checklist

下列資料全部延後，不阻擋本機架構與 Mock 完成，也不得以真實值提交到 repository。

## Platform owner（future only）

- [ ] 公司／商業名稱與必要時的平台統編
- [ ] 業務、技術與資安聯絡人
- [ ] Production domain、隱私權、條款及資料處理文件
- [ ] Provider partnership contract（若採平台模式）

## 每一商家

- [ ] 法律賣方名稱、統編、稅籍、登記地址與聯絡人
- [ ] 電子發票資格與字軌授權
- [ ] Provider、merchant account、API credential 與授權範圍
- [ ] 稅別、B2C/B2B、載具、捐贈需求及開票政策
- [ ] Sandbox 測試證據與 Production 核准

## Infrastructure

- [ ] HTTPS domain、callback/webhook URL
- [ ] secret storage、key rotation、monitoring、alerting、backup
- [ ] incident contact、runbook、DR 與 audit retention
