# 產品模組矩陣

| 代碼 | 中文名稱 | 主要使用者 | 本機入口 | 預設 |
| --- | --- | --- | --- | --- |
| CORE_OPS | 核心營運 | 店主、店員、廚房 | `/merchant/dashboard` | 開啟 |
| GROWTH | 會員與成長 | 店主、行銷 | `/merchant/growth` | 關閉 |
| OMNI | 全通路整合 | 店主、系統管理者 | `/merchant/integrations` | 關閉 |
| HQ | 總部治理 | 組織管理者 | `/merchant/catalog/versions` | 關閉 |
| SUPPLY_LITE | 輕量供應 | 店主、庫存人員 | `/merchant/supply` | 關閉 |
| EVENT_GROWTH | 活動成長 | 店主、活動營運 | `/merchant/event-growth` | 關閉 |
| PUBLIC_API | 公開 API | 技術管理者 | `/merchant/developer` | 關閉 |
| ADVANCED_ANALYTICS | 進階分析 | 店主、財務 | `/merchant/analytics/advanced` | 關閉 |

所有進階模組以 Organization override 開啟；本機 seed 只為示範組織開啟可測模組，不更改全域預設。
