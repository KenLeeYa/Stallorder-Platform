# 競品功能映射

本文件用來說明產品能力，不宣稱完全複製任何競品。

| 市場常見能力 | Stellorder 對應 | 差異化 |
| --- | --- | --- |
| 多通路菜單 | Channel-aware catalog | 可審核版本、攤位／區域覆寫、發布 receipt |
| CRM／優惠 | Growth foundation | 同意 hard-lock、預算、頻率、每客上限 |
| 輕量庫存 | Supply Lite | 不可變 ledger、配方、移動平均成本 |
| 市集／活動 QR | Event Growth | 簽章來源、費用、估算與信心分數 |
| 開放平台 | Public API/Webhook | Scoped key、hash-only、HMAC、fail-closed |
| 營運分析 | Advanced Analytics | KPI 中文定義、來源、新鮮度與限制同頁呈現 |

不在本階段建立大型 ERP、真實推薦 AI、現金分潤出款或未經供應商核准的外送／金流寫入。
