# Actual Batch 2 catalog search and report reads

Catalog browse/search use one bounded authorized database module, not filtering the current client page. Inputs are trimmed/NFC, limited to 80 characters, and reject controls. Current matching is literal case-insensitive substring across product name and stored translations, plus existing taxonomy/active/authorized-stall filters. `%`, `_`, backslash and slash stay literal; SQL field names/sort fragments are never accepted. Stable ordering includes ID ties; count and rows share a repeatable-read authorized scope.

Actual frozen-corpus readback ranks `奶茶` as 奶茶/珍珠奶茶/珍珠鮮奶茶; `珍珠奶茶` matches itself, and mixed-case `pEaRl MiLk TeA` matches the stored English translation. `%`, `_`, backslash and slash each match only the literal fixture product. `FOREIGN ONLY` is invisible in org A and visible in org B. `台湾`, `zhen zhu` and `波霸` have no matches: simplified/traditional normalization, pinyin, synonyms and fuzzy/token ranking are not implemented or claimed.

The actual list debounces search 300ms, resets page before a changed search/filter/sort/page size, uses a manual server-driven TanStack Table row model, and retains URL state. Lazy complete editing is separate from first browse and uses the full authorized catalog snapshot; CSV remains with its existing command owner. CSV string cells with leading control/whitespace followed by formula characters are escaped while actual negative numeric values retain numeric meaning.

Order history retains existing report routing with DR_PREFERRED_EVENTUAL and maximum lag 30 seconds. The local environment has no enabled DR read target: actual readback is PRIMARY / FEATURE_DISABLED. Neither primary contents nor a successful local read prove DR freshness. Report list/detail are projections for existing screens; no new BI service, export scheduler, materialized view, dashboard subscription or financial completion owner was created.

Measurement uses the same fixed synthetic corpus and user-visible document entrances before/after. BEFORE used existing RSC/document transport; bounded AFTER APIs are new, so transport equivalence is not claimed. Thirty warm samples after five warmups and twenty fresh browser contexts per page are retained. Database query count is UNAVAILABLE. Browser first browse and complete editor-open are reported separately; increased JavaScript bytes and history timing regressions remain visible in the Batch 2 report.
