Server authorization creates opaque principal/session/permission fingerprints in `src/server/operations-read-scope.ts`; client keys include environment, all fingerprints, discriminated organization/platform context with sorted unique stall IDs, resource and normalized input. The key is cache identity, never a grant. Each RSC invocation creates its own QueryClient and hydrates only its authorized selected result. No persistent private Query cache, client Prisma import or module-global server QueryClient was introduced.

The scoped provider cancels/clears reads and unmounts private children on denials and the existing logout/current-session revoke/logout-all handling seam. Full manager async callbacks capture authority generation and ignore results after unmount/scope loss. Logout does not remove POS/outbox records or bypass the original offline-pending/CSRF/session workflow. Workspace selection still uses the existing full-document `window.location.assign`; controlled ignoring-AbortSignal fault injection is not a product SPA switch claim.

Read retries: at most two automatic retries for network/eligible 500/502/503/504. No automatic retry for schema failure, 401/403/concealed404/409 or abort. Valid 429 seconds/date retain the entire deadline on the cached Query object. Automatic failure retry is limited to deadlines within 60 seconds; longer failures remain visible. Later manual, focus or reconnect triggers still wait at the common fetch boundary until the retained deadline. Recreated observer options cannot reset that wait. Three real toolbars and lazy editor use the same manual deadline guard. Invalid Retry-After has no automatic retry. Scope cancellation remains immediate during waits. Mutations have no automatic retry or optimistic approval/payment completion. Admin uncertain writes display uncertainty and reread the same case before manual reconsideration.

Focus/reconnect reauthorize reads. There is no server grant-push channel: display purge for another-tab revocation occurs on the next authorized read, and measured detection latency is reported separately. No additional Staff poller/subscription was introduced.
