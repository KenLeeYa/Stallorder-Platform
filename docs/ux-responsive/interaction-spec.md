# 互動規格（設計已核准；分階段實作中）

本規格只調整既有任務的呈現與可靠操作，不新增產品能力、付款方式、通知授權或角色權限。

## 2026-09-30 A3 顧客選餐與結帳

顧客在 320–1023px 使用單欄菜單與底部購物車入口；開啟購物車後以可捲動的單一面板完成核對與結帳。1024px 起菜單與 340px 摘要並列。切換寬度時維持同一個點餐 controller、已選規格與兩份商品數量；從窄版進入並列版會收起手機購物車面板，重返窄版仍可由底部入口展開。CSS 與 dialog `matchMedia` 使用相同的 1024px 界線。

規格選擇的價格差額、必選未選提示、最後一個選項與提交動作需在 320/360/390px 可讀、可捲動且不被固定 footer 遮蓋。成立訂單後使用原追蹤 token 回到同一筆訂單；刷新與返回不得重建訂單。售罄或伺服器拒絕時保留其餘有效購物車，沿既有錯誤與安全重試流程恢復。公開 Menu 切外帶須到可操作購物車的點餐頁。

本節是隔離本機候選，未發布；A3 顧客瀏覽器 9 個案例、受影響單元 49 個案例及記錄來源的 production build 通過，細節記在任務報告。完整跨任務、語系與主題矩陣由後續整合驗收。

## 2026-09-30 A2 本機實作

`ExperienceDialog` 保留原有呼叫介面，新增預設為 `false` 的 `closeDisabled` 與預設外觀不變的 `size="workspace"`。原生 `cancel` 一律先 `preventDefault()`，再依可否關閉走單一 `onClose`；禁用時關閉按鈕亦不可操作。Staff POS 主視窗、商品客製、整單備註及暫存單使用原生 modal 生命週期；同一個 composer 保有待處理請求及冪等鍵，送單 `busy` 時 Escape 和關閉鍵都不能卸載。有內容草稿的 Escape／關閉鍵共用放棄確認；取消確認時商品數量、選項與備註留在原 composer。巢狀 Escape 只關最上層，Tab 留在作用中的視窗；關閉 POS 返回「店員點餐」觸發鍵。QR 商品客製沿既有 controller 的單一焦點路徑返回原「選擇規格」鍵，找不到可操作鍵時退回商品卡。

此節僅為隔離本機候選，未發布。`e2e/responsive-dialog-keyboard.spec.ts` 的 9 個實際瀏覽器案例、4 個受影響 Vitest 檔案的 19 個案例、範圍 lint／型別與記錄來源的 production build 通過；完整跨任務整合矩陣另由後續驗收執行。

## 共用生命週期

- Dialog：開啟後焦點到標題／第一個合適欄位；背景不可Tab進入；Tab／Shift-Tab循環；Escape走同一close path；關閉返回原觸發按鈕。巢狀客製只關最上層。草稿變更依既有確認政策處理，不能丟資料。
- Scroll：主頁只垂直捲動；工作台每欄獨立scroll；header/close/footer可到達；sticky footer以實際高度留內容padding，不掩蓋最後錯誤、商品與安全區。
- 返回：維持org/stall、query、filter、sort、page、selected order與可安全保存的draft；身份／門市切換隔離而非把A店草稿搬至B店。
- 旋轉：CSS改layout不重新建立controller；原選單/草稿不丟失；新的角色與server snapshot仍須讀回。原selected order已不在權限／結果集合則提供明確狀態，不顯示過期操作。
- 手機明細sheet：保留單號、來源、總額、付款和製作狀態；品項／備註完整可讀。關閉後回到原卡片位置；不把現有卡片內容永久刪除。
- 圖示：aria-label與可觸及的說明；tooltip不作唯一說明。狀態同時有圖示與文字替代，連線色彩不能取代可存取狀態。

## POS 收款保留既有決議

本次訂單標頭同時顯示份數／總額。折扣、200／500／1000與實收在有足夠寬度時同排；快捷按鈕視覺可緊湊，但觸控命中至少44px。實收用短數字欄位，不限制合法金額只能4位數；金額上限仍依既有server規則。手機必要時有序折行而非壓縮字元。找零以大字、文字「應找零」及獨立surface呈現；不足則顯示「尚差」，不能用負數冒充找零。

付款提交pending期間鎖同一提交；沿用目前busy時禁止關閉POS的保護，不任意卸載controller或清掉attempt／冪等鍵。結果未知時保留原attempt查詢／恢復入口，確定前不可建立新attempt。逾時顯示「付款結果待確認」，先查原attempt；列印pending/failed另列，不讓列印重試觸發新付款或新訂單。

## 完整狀態

| 情況 | 呈現 | 可執行恢復 |
|---|---|---|
| Loading | 保留穩定區塊尺寸，局部busy與原資料更新中 | 安全返回；避免整頁閃空 |
| Empty | 說明目前日期／篩選無資料 | 清除篩選／回今日；不是泛用server error |
| 401／403 | 身份失效／無權限；遮蔽先前資料 | 原安全登入／回授權工作區；不得只留cached screen |
| 409 | 訂單已由其他裝置更新，顯示最新狀態 | 重新核對；不盲重送收款／交付 |
| 422／售罄 | 欄位／品項原因就近顯示，加error summary | 保留有效草稿，移除或重選失效項 |
| 429 | 等待重试，遵守Retry-After | 有界倒數／手動重試，不持續轟炸 |
| 500／非JSON | 保留安全草稿，顯示可追踪但不含secret的錯誤 | 查原結果後安全重試；不把HTML灌入畫面 |
| Offline／stale | 最後同步時間＋離線文字＋圖示 | 只允許既有合法offline queue；不新增離線付款能力 |
| Partial success | 訂單成功、通知/列印另有結果 | 分別重試有權限的子任務；原單不消失 |
| QR過期／已用 | 各自具體原因；掃描預覽不交付 | 依法取得新有效碼或人工核對原流程 |

一律使用目前語系；新增文案同時涵蓋繁中與既有非中文。狀態更動用適度aria-live提示；不以每次輪詢整頁廣播干擾螢幕閱讀器。
