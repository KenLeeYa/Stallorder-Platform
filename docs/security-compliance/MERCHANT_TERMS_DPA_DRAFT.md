# SaaS／DPA／顧客條款草稿
DRAFT／2026-09-13；法律主體、價格附件、管轄與窗口待法務/會計確認。本次未發布、未取得簽署、未追溯改約。

SaaS以已啟用能力為範圍，維持Organization/Stall隔離。商家負責合法商品、履約、員工授權與退款告知，平台維護系統及受託安全處理。付款由商家與合格provider處理，平台不取得資金保管/調度權。

PAYG沿用不可變PlanVersion、每攤每月完成訂單淨計量及既有TWD1/筆、1499封頂方案；含稅/未稅、跨月退款/折抵及實際版本以既有政策和會計核定為準。本次未修改費率、關帳或發票；爭議用ledger/reversal，不改舊帳單。

停用、最後owner移轉、匯出/終止需授權與證據；權利/可攜/刪除不可被不必要費用或身份文件阻擋。SLA、RTO/RPO、賠償不可填未實測保證。

DPA必填：目的/期間/資料/當事人、處理地區/次處理者、書面指示與違法指示、保密/人員權限、最低安全、權利協助、事件通知/補報期限、稽核、返還/刪除/必要保全、跨境依據/終止證明。契約較短期限需進incident register。

顧客交易前明示商家、品項價格稅費、履約、取消、取餐外送、支付退款及申訴窗口。易腐敗或短保存期例外逐項適用並事先告知，一般零售不概括排除七日解除權；瑕疵錯單未履約另依法處理。退款依原交易/原對象/累計上限；列印開櫃不代表付款或交付。申訴15日妥適處理，保留交易當時條款/告知/費率版本。
