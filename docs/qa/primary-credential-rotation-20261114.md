## Managed-role cleanup correction before issuance

The pre-execution review found an Important issue in the original cleanup design. PostgreSQL 17 requires a non-superuser to have both CREATEROLE and ADMIN OPTION for the target role before DROP ROLE. Supabase documents that CLI roles belong to supabase_admin and cannot be dropped through ordinary postgres SQL. The old synthetic cleanup fixture incorrectly accepted that SQL. No hosted credential probe or issuance was performed before this finding.
